## 📅 カレッジ・カリキュラム（4段階の覚醒フェーズ）

### 【第1段階（Phase 1）：レガシー物理・覇権経済のパージ】
* **目的:** 既存の「金利・債務・特許・GPU物量依存AI」の限界を見抜き、C＠I＿Pressの哲学を脳波へラッチする。
* **学習リソース:** `/docs/SF_MANIFESTO.md` および `GOVERNANCE_PROTOCOL.md` の静観読解。
* **課題:** 特許開示義務制度の脆弱性と、著作権（無方式主義）＋SF著作による防衛線の優位性を2000字以内で論理記述せよ（`/college/submissions/phase1_YourNodeID.md` へコミット）。

### 【第2段階（Phase 2）：16元数位相平面と1nsワンショット論理の解析】
* **目的:** `qpu_1mbit_ultimate_unified_core.v` のRTL記述を完全に理解し、PCシミュレーションを執行する。
* **学習リソース:** Icarus Verilog ＋ GTKWaveによる波形解析、および `VenusDecorInterrelationSimulator`（Pythonコード）の実行。
* **課題:** OLSWS走査（1024ステップ）中に発生する高次元ハザードを、DECOR回路が `margin_reg_we` によって1ns真空隔離パージする波形（VCD）を出力し、そのスクリーンショットを提出せよ。

### 【第3段階（Phase 3）：オープンソースASIC物理設計（GDSIIマップ自動生成）】
* **目的:** 巨額のEDAライセンスをバイパスし、完成したQPUコアを自身のPCでASICチップの「肉体」へマッピングする。
* **学習リソース:** `/ASIC_ENVIRONMENT.md` （OpenLaneスタック ＋ SkyWater PDK）。
* **課題:** 自身の拡張XaaS回路（DECOR連動面）をインクルードした状態で OpenLane フローを完全完走させ、DRC（製造規則違反）ゼロ、タイミング収束1.0nsを達成した `final.gds` マスクデータを生成せよ。

### 【第4段階（Phase 4）：C＠I＿Press XaaS経済圏サプライチェーンの構築】
* **目的:** Apple社製エッジデバイス（MacBook/iPhone等）への統合を見据え、QPU内部構造と連動した自律循環型XaaS（GatherCast等）の実態を地球上に解禁する。
* **課題:** `src/kernel/boot_sequence.py` へ自身のASICポートをフックする起動スクリプトを記述し、QPUの演算執行（1ns）と同時にギークウォレットへ富が正に還流するスマートコントラクトを実証せよ。
